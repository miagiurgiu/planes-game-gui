--- ## Overview Developed as an enhancement of the Fundamentals of Programming Semester 1 project, **Planes Game** is a turn-based strategy game (human vs. computer) played on an 11x11 grid. The core objective is to locate and destroy the heads of all 3 opponent aircraft before they destroy yours. The application strictly implements **layered object-oriented architecture**, clean separation of concerns, robust input validation, comprehensive PyUnit tests, and dual interface support (CLI and modern styled Tkinter GUI). --- ## Key Features * **Dual User Interfaces**: Choose between a command-line interface or a custom retro pixel-art themed Tkinter GUI at startup. * **Smart Game Computer AI**: Employs dynamic target tracking, pattern matching, and head-guessing routines tailored for hidden-information gameplay. * **Input Protection**: Full input validation preventing invalid formats, out-of-bounds plane placements, overlapping aircraft, or redundant attacks. * **Layered Design**: Shared service and repository components powering both console and graphical views seamlessly. --- ## Architecture The project strictly follows a **Layered Architecture**: ```text ├── domain/ # Grid representation and cell state constants ├── repository/ # Dual board tracking, hit/miss sets, plane placements ├── service/ # Game mechanics, placement validation, computer AI ├── validation/ # Input coordinate syntax checks (A1-J10 format) ├── ui/ # ConsoleUI & Tkinter ConsoleGUI views └── main.py # Entry point for launcher selection ``` --- ## Artificial Intelligence (AI) Strategy Because Battleship/Planes is an **imperfect information game**, standard Minimax search cannot be directly applied. Instead, the computer opponent uses a rule-based hunting and pattern detection strategy: 1. **Target Pursuit**: Prioritizes adjacent orthogonal cells stored in a target queue following a successful hit. 2. **Head Detection (Pattern Match)**: Analyzes hit lines (`XXX` horizontally or vertically) to project candidate plane head positions (`_guess_head_from_hits`). 3. **Head Elimination Rules**: When a plane head is destroyed, the AI clears its localized target queue and registers the full plane destruction. 4. **Fallback Exploration**: Plays random untried grid cells when no active target patterns exist. --- ## Setup & Running ### Requirements * Python 3.x * `Pillow` library (for GUI graphics rendering) ### Execution Run the application entry point: ```bash python main.py ``` Select the mode when prompted: ```text Choose interface (ui/gui): gui ``` --- ## Testing & Validation All core logic layers (Repository, Service, Validation) include comprehensive unit test coverage using PyUnit (`unittest`): * Coordinate parsing & boundary validation * Overlap & bounds handling during plane placement * User move state updates (hits, misses, head destruction) * Game-over & draw conditions Run test cases with: ```bash python -m unittest discover tests ```
